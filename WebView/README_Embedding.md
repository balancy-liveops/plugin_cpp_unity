# Balancy WebView Unity Embedding Guide\n\nThis guide explains how to use the Unity Embedding functionality for Balancy WebView on macOS.\n\n## Overview\n\nThe Balancy WebView now supports two modes:\n1. **Popup Mode**: Traditional overlay WebView (existing functionality)\n2. **Embedded Mode**: WebView content rendered to a Unity RenderTexture (new functionality)\n\n## Features\n\n### Embedded Mode\n- Renders WebView content directly to a Unity RenderTexture\n- Can be displayed on any 3D object or UI element\n- Supports mouse interaction through raycasting\n- Works only in Unity Editor on macOS (for development)\n- Hidden WebView window (content is captured to texture)\n\n### Popup Mode\n- Traditional overlay WebView window\n- Works on macOS builds and in editor\n- Full native WebView experience\n\n## Setup\n\n### 1. Build the Native Library\n\nRun the build script to compile the native library with embedding support:\n\n```bash\ncd /Volumes/PavelData/Projects/plugin_cpp_unity/Assets/Balancy/WebView/Plugins/macOS\n./build_macos.sh\n```\n\nThis will create `libBalancyWebViewMac.dylib` with the new embedding functionality.\n\n### 2. Unity Components\n\nTwo main components are available:\n\n#### BalancyWebView (Main Class)\n- Singleton class that manages WebView instances\n- Supports both popup and embedded modes\n- Use `OpenWebView()` for popup mode\n- Use `LoadEmbedded()` for embedded mode\n\n#### BalancyWebViewEmbedded (Embedded Component)\n- Component that can be attached to GameObjects\n- Automatically creates and manages RenderTexture\n- Handles mouse input through raycasting\n- Requires a Renderer component on the GameObject\n\n## Usage Examples\n\n### Basic Embedded WebView\n\n```csharp\n// Get or create the embedded component\nvar embeddedWebView = gameObject.GetComponent<BalancyWebViewEmbedded>();\nif (embeddedWebView == null)\n{\n    embeddedWebView = gameObject.AddComponent<BalancyWebViewEmbedded>();\n}\n\n// Load a webpage\nembeddedWebView.InitializeEmbeddedWebView(\"https://www.google.com\");\n\n// Handle events\nembeddedWebView.OnLoadCompleted += (success) => {\n    Debug.Log($\"WebView loaded: {success}\");\n};\n\nembeddedWebView.OnMessage += (message) => {\n    Debug.Log($\"Received: {message}\");\n    return \"Response from Unity\";\n};\n```\n\n### Using the Main WebView Class\n\n```csharp\n// Get singleton instance\nvar webView = BalancyWebView.Instance;\n\n// For embedded mode\nRenderTexture renderTexture = new RenderTexture(1024, 768, 24);\nwebView.LoadEmbedded(\"https://example.com\", renderTexture, \"{}\");\n\n// For popup mode\nwebView.OpenWebView(\"https://example.com\", \"{}\");\n\n// Send messages\nwebView.SendMessageToWebView(\"{\\\"action\\\": \\\"test\\\"}\");\n\n// Handle mouse input (for embedded mode)\nwebView.SendMouseEvent(x, y, true); // x, y in pixels, true for click\n```\n\n### Mode Switching\n\n```csharp\npublic class WebViewManager : MonoBehaviour\n{\n    private bool useEmbeddedMode = true;\n    private BalancyWebView webView;\n    private BalancyWebViewEmbedded embeddedComponent;\n    \n    void Start()\n    {\n        webView = BalancyWebView.Instance;\n        embeddedComponent = GetComponent<BalancyWebViewEmbedded>();\n    }\n    \n    public void ToggleMode()\n    {\n        // Close current WebView\n        if (useEmbeddedMode)\n        {\n            embeddedComponent?.CloseEmbeddedWebView();\n        }\n        else\n        {\n            webView?.CloseWebView();\n        }\n        \n        // Switch mode\n        useEmbeddedMode = !useEmbeddedMode;\n        \n        // Open in new mode\n        if (useEmbeddedMode)\n        {\n            embeddedComponent?.InitializeEmbeddedWebView(\"https://example.com\");\n        }\n        else\n        {\n            webView?.OpenWebView(\"https://example.com\", \"{}\");\n        }\n    }\n}\n```\n\n## Example Scene Setup\n\n1. Create a GameObject (e.g., a Quad or Cube)\n2. Add the `BalancyWebViewEmbedded` component\n3. Add the `BalancyWebViewEmbeddedExample` component for a complete demo\n4. Configure the URL and texture size in the inspector\n5. Run in Unity Editor (macOS only)\n\n## JavaScript Integration\n\nSame as the regular WebView - use the Balancy WebView JavaScript bridge:\n\n```javascript\n// Send message to Unity\nwindow.BalancyWebView.postMessage(JSON.stringify({\n    action: \"buttonClick\",\n    data: \"Hello Unity!\"\n}));\n\n// Listen for messages from Unity\ndocument.addEventListener('balancyMessage', function(e) {\n    console.log('Message from Unity:', e.detail);\n});\n```\n\n## Platform Support\n\n- **Embedded Mode**: Unity Editor on macOS only\n- **Popup Mode**: macOS builds and Unity Editor\n\nThe embedded mode is designed for development and testing in the Unity Editor. For production builds, use the popup mode.\n\n## API Reference\n\n### BalancyWebView Methods\n\n```csharp\n// Embedded mode\nbool LoadEmbedded(string url, RenderTexture renderTexture, string ownerJson)\nvoid CloseEmbedded()\nvoid UpdateEmbeddedTexture(RenderTexture renderTexture)\nvoid SendMouseEvent(int x, int y, bool isClick)\nbool IsWebViewEmbedded()\n\n// Existing popup mode methods\nbool OpenWebView(string url, string ownerJson)\nvoid CloseWebView()\nbool SendMessageToWebView(string message)\n// ... other existing methods\n```\n\n### BalancyWebViewEmbedded Methods\n\n```csharp\nvoid InitializeEmbeddedWebView(string url = null)\nvoid CloseEmbeddedWebView()\nbool SendMessage(string message)\nvoid Reload()\nvoid NavigateTo(string url)\nRenderTexture GetRenderTexture()\nvoid SetTextureSize(int width, int height)\n```\n\n### Events\n\n```csharp\nevent Action<bool> OnLoadCompleted\nevent Func<string, string> OnMessage\nevent Action OnClosed\n```\n\n## Troubleshooting\n\n### Common Issues\n\n1. **WebView not appearing in embedded mode**\n   - Ensure you're running in Unity Editor on macOS\n   - Check that the RenderTexture is properly assigned to the material\n   - Verify the native library was built with embedding support\n\n2. **Mouse input not working**\n   - Ensure the GameObject has a Collider component\n   - Check that the main camera is tagged as \"MainCamera\"\n   - Verify raycasting is working by testing with other objects\n\n3. **Build errors**\n   - Make sure all required frameworks are linked (Cocoa, WebKit, QuartzCore, CoreGraphics)\n   - Verify the native library is in the correct location\n   - Check Unity console for detailed error messages\n\n### Debug Logging\n\nEnable debug logging to troubleshoot issues:\n\n```csharp\nBalancyWebView.Instance.SetDebugLogging(true);\n```\n\nThis will output detailed logs to the Unity console and system console.\n\n## Limitations\n\n- Embedded mode only works in Unity Editor on macOS\n- Texture rendering is at 30 FPS (configurable in native code)\n- Some advanced WebView features may not work in embedded mode\n- Mouse input is basic (click only, no hover or drag)\n\n## Future Improvements\n\n- Support for other platforms (Windows, Linux)\n- Better mouse/keyboard input handling\n- Higher frame rate rendering options\n- Support for Unity builds (not just editor)\n
